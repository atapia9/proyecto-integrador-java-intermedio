# Ejemplo guía — Tema "Mascotas"

Esta carpeta contiene el proyecto **completo y resuelto**, día por día, usando el tema "Mascotas":

- Clase base: `Mascota` (atributos: `nombre`, `raza`, `edad`)
- Subclases: `Perro`, `Gato`
- Interfaz: `Cuidable` (método `obtenerCuidados()`)
- Gestor de colección: `GestorMascotas`
- Excepción propia: `DatoInvalidoException` (se lanza si `edad` es negativa)

Úsala como referencia cuando te atores en tu propia opción (A, B o C). La estructura de cada carpeta (`dia1-clase-base`, `dia2-herencia`, etc.) es idéntica a la de tu proyecto; solo cambian los nombres de las clases y los datos.

No copies y pegues este código tal cual para tu entrega: la idea es que lo uses para **entender el patrón** y lo adaptes con los nombres de tu opción elegida.
